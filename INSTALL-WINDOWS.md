# Установка Pulse через GitHub Actions и Sideloadly

Свой Mac не нужен: GitHub соберёт приложение на macOS, Sideloadly на Windows подпишет его и установит на iPhone. Приложение требует iOS 17 или новее.

## Что подготовить

- Компьютер с Windows, интернет и USB-кабель с передачей данных.
- iPhone с iOS 17 или новее, кодом разблокировки и доступом к настройкам устройства.
- Аккаунт [GitHub](https://github.com/). Платный план не обязателен. Бесплатный лимит Actions в закрытом репозитории ограничен; сборки на macOS расходуют его быстрее Linux. Актуальные лимиты и использование смотрите в настройках GitHub Billing. На бесплатном плане сборки могут остановиться после исчерпания лимита.
- Обычный Apple Account (Apple ID); платный Apple Developer для этого варианта не требуется.
- [Sideloadly для Windows с официального сайта](https://sideloadly.io/), а также компоненты Apple/iTunes по инструкции этого сайта, чтобы компьютер видел iPhone.
- Распакованный архив Pulse с папкой `.github`.

Apple ID и пароль нужны только для локальной подписи в Sideloadly. В GitHub Secrets ничего добавлять не требуется.

## 1. Загрузить проект на GitHub

1. Войдите на GitHub, нажмите **+ → New repository**, назовите репозиторий, например `pulse-iphone`.
2. Выберите **Private**, включите **Add a README file** и создайте репозиторий. Это позволит сразу открыть страницу загрузки файлов.
3. Нажмите **Add file → Upload files**. Перетащите **содержимое** распакованной папки `Pulse` и нажмите **Commit changes**. Исходный README GitHub можно заменить README из проекта. Сам ZIP загружать не нужно.
4. Проверьте, что в корне репозитория лежат `Pulse.xcodeproj`, папка `Pulse`, файл `validate_project.py` и `.github/workflows/build-ios.yml`. Дополнительная внешняя папка `Pulse` в корне не нужна.
5. Если папка `.github` не загрузилась, нажмите **Add file → Create new file**, укажите имя `.github/workflows/build-ios.yml` и скопируйте в него содержимое этого файла из архива. Нажмите **Commit changes**.

Код остаётся в вашем репозитории. Действия выполняются на временной машине GitHub; аккаунт Apple к ней не подключается.

## 2. Получить IPA

1. Откройте вкладку **Actions**. Если GitHub просит включить Actions, разрешите их для этого репозитория.
2. Выберите **Build iPhone IPA → Run workflow → Run workflow**. Если сборка уже запустилась после загрузки файлов, повторный запуск не нужен.
3. Дождитесь зелёного результата. Первая сборка одновременно проверяет компиляцию исходников: локально в нашей Linux-среде Xcode отсутствовал.
4. Откройте завершённый запуск, прокрутите к разделу **Artifacts**, скачайте **Pulse-iPhone-unsigned**.
5. Распакуйте скачанный ZIP: внутри будет **Pulse-unsigned.ipa**. Его не нужно распаковывать или переименовывать.

Файл IPA ещё не подписан и не устанавливается простым открытием на iPhone. Подпись выполнит Sideloadly. Артефакты хранятся 7 дней; позднее можно запустить сборку заново.

Если сборка красная: откройте шаг **Build unsigned app for a physical iPhone**, найдите сообщение `error:` или скачайте артефакт **Pulse-build-log**. Сохраните этот текст для исправления. Зелёная сборка проверяет компиляцию, но не звук и Siri на реальном устройстве.

## 3. Установить через Sideloadly

1. Установите Sideloadly и необходимые компоненты Apple по инструкции его сайта.
2. Подключите разблокированный iPhone по USB. На телефоне выберите **Доверять этому компьютеру** и введите код устройства.
3. Запустите Sideloadly и выберите iPhone в списке устройств.
4. Перетащите **Pulse-unsigned.ipa** в окно Sideloadly. Укажите Apple ID и нажмите **Start**. Выполните запросы входа и двухфакторной аутентификации.
5. Если iPhone не разрешает запуск, откройте **Настройки → Основные → VPN и управление устройством**, найдите профиль своего Apple ID и подтвердите доверие. Названия пунктов зависят от версии и языка iOS.
6. Если iOS запрашивает режим разработчика, откройте **Настройки → Конфиденциальность и безопасность → Режим разработчика**, включите его и подтвердите после перезагрузки. Пункт может появиться после первой попытки установки.
7. Откройте Pulse, нажмите **+ → Выбрать папки** или **Выбрать файлы** и импортируйте музыку.

Если Sideloadly не видит iPhone, сначала убедитесь, что его видит ПО Apple на Windows и подтверждено доверие компьютеру. Если сборка или установка завершается ошибкой, сохраните текст ошибки; разные этапы требуют разных исправлений.

## Бесплатная подпись и обновления

С бесплатным Apple ID подпись обычно действует 7 дней. Затем приложение перестаёт запускаться, пока подпись не будет обновлена. Обычно также действует ограничение до 3 приложений с такой подписью на устройстве.

Для обновления повторите установку через Sideloadly с тем же Apple ID и идентификатором приложения. Не удаляйте Pulse перед обновлением: удаление сотрёт импортированную музыку и библиотеку. Сохраняйте исходные музыкальные файлы отдельно.

Sideloadly поддерживает обновление подписи; возможность автоматического обновления и требования к работающему компьютеру/подключению смотрите в текущей версии программы. Бесплатная подпись не становится бессрочной.

Платное членство Apple Developer не обязательно для начала. Оно потребуется для другого способа распространения, например TestFlight, с отдельной настройкой подписи.
