# Pulse для iPhone

Первая версия локального музыкального плеера на SwiftUI, с тёмным интерфейсом в духе Poweramp. Без эквалайзера, сторонних SDK, рекламы и серверов. Это самостоятельный интерфейс, не точная копия Poweramp.

## Что реализовано в исходниках

- Выбор отдельных файлов и папок через системное приложение «Файлы», рекурсивное сканирование папок.
- Копирование музыки в хранилище Pulse для работы без интернета; поиск дубликатов по SHA-256.
- Сохранение доступа к выбранным папкам и повторное сканирование вручную или командой Siri.
- Названия, исполнители, альбомы, длительность и обложки из метаданных файлов.
- Поиск, альбомы, исполнители, избранное и плейлисты. Удерживайте трек для меню добавления; смахните трек в плейлисте для удаления из него.
- Очередь, перемешивание, повтор трека/очереди, перемотка, системная громкость, выбор аудиовыхода AirPlay.
- Крупная обложка с жестами влево/вправо для переключения треков, мини-плеер.
- Фоновый звук, команды с экрана блокировки и наушников; пауза при отключении наушников, обработка аудиопрерываний.
- Сохранение очереди и позиции; при следующем запуске воспроизведение остаётся на паузе.
- App Intents / App Shortcuts для Siri и приложения «Команды».

## Как установить

**Нет Mac?** В проект добавлена сборка через GitHub Actions с последующей локальной подписью и установкой через Sideloadly на Windows. См. [пошаговую инструкцию](INSTALL-WINDOWS.md). Сборка не требует Apple ID или секретов в GitHub. Workflow успешно выполнен на Xcode 16.4.

Готовая сборка: [успешный запуск Actions](https://github.com/SxeigumenNew/iphoneAppPlayer/actions/runs/40288536100). В разделе **Artifacts** скачайте **Pulse-iPhone-unsigned**, распакуйте ZIP и передайте `Pulse-unsigned.ipa` в Sideloadly. Артефакт хранится 7 дней; затем запустите workflow повторно. Скачать исходники можно через **Code → Download ZIP** в этом репозитории.

Для установки напрямую через Xcode нужны Mac, Xcode 16 или новее и iPhone с iOS 17 или новее. Сторонние зависимости и XcodeGen не требуются.

1. Откройте `Pulse.xcodeproj` в Xcode и выберите схему **Pulse**.
2. В **Signing & Capabilities** выберите свою Team и задайте уникальный Bundle Identifier вместо `com.example.Pulse`.
3. Подключите iPhone, при необходимости включите на нём режим разработчика, выберите его как устройство запуска и нажмите **Run**.
4. Нажмите **+ → Выбрать папки** или **Выбрать файлы**. Для файлов в iCloud сначала используйте «Загрузить сейчас» в приложении «Файлы».

Для личной установки можно использовать бесплатную Personal Team; такая подпись обычно требует переустановки через Xcode каждые 7 дней. Для TestFlight и App Store потребуется платное членство Apple Developer, иконка приложения и подготовка к публикации.

Пример сборки на Mac без подписи:

```sh
xcodebuild -project Pulse.xcodeproj -scheme Pulse -configuration Debug -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
```

## Siri

После установки откройте Pulse и импортируйте музыку. Доступны фразы:

- «Siri, включи музыку в Pulse».
- «Siri, пауза в Pulse».
- «Siri, следующий трек в Pulse».
- «Siri, обнови библиотеку в Pulse».

Команды открывают приложение для выполнения. Произношение Pulse и доступность фраз зависят от языка Siri и должны быть проверены на устройстве. Для выбора конкретного трека или исполнителя создайте команду в приложении «Команды», добавьте действие Pulse **Включить музыку** и заполните параметр **Трек или исполнитель**. Произвольный голосовой поиск по всей медиатеке через SiriKit Media здесь не реализован.

## Ограничения первой версии

- iOS не разрешает приложениям сканировать всю память iPhone. Доступны только выбранные пользователем папки и файлы. Некоторые файловые провайдеры ограничивают доступ к папкам; в таком случае выбирайте отдельные файлы.
- Импорт занимает дополнительное место. Копии музыки и индекс исключены из резервного копирования iCloud; сохраните исходные файлы. После удаления приложения его библиотека удаляется.
- Повторное сканирование добавляет новые файлы, но не синхронизирует удаления и изменения тегов у уже импортированных копий. Изменённый по содержимому файл считается новым треком.
- При больших библиотеках держите приложение открытым во время импорта. Продолжение сканирования после завершения процесса iOS не предусмотрено. Импорт обрабатывает файлы последовательно и показывает итоговый отчёт.
- Кандидаты на импорт: MP3, M4A, M4B, AAC, WAV, AIFF, CAF, FLAC и MP4 с воспроизводимым аудио. Реальное декодирование выполняет AVFoundation; контейнер не гарантирует поддержку любого кодека внутри. Защищённые файлы и подписка Apple Music не поддерживаются. Интеграции с медиатекой «Музыки» пока нет.
- Нет собственного набора декодеров, гарантированного gapless, crossfade, ReplayGain, редактора тегов, таймера сна, CarPlay и точной копии интерфейса Poweramp. Эквалайзера нет по условию задачи.
- Нет удаления импортированных файлов через интерфейс и редактирования порядка очереди/плейлистов; можно удалять плейлисты и убирать из них треки.

## Проверки и статус

26 октября 2026 года в GitHub Actions успешно выполнена Release-сборка для физического iPhone на Xcode 16.4 / iOS SDK 18.5 с минимальной версией iOS 17. Пройдены компиляция Swift, извлечение метаданных App Intents, упаковка и проверка структуры IPA. Дополнительно проверены plist/JSON, структура проекта, ссылки на исходники и схема. Подпись, установка, запуск, звук и Siri на реальном iPhone **не проверены**. Артефакт содержит неподписанный IPA для локальной подписи в Sideloadly.

Повторить проверку структуры проекта без Xcode: `python3 validate_project.py`. Эта проверка не проверяет синтаксис Swift и не заменяет сборку.

Проверки на Mac/iPhone перед повседневным использованием:

1. Собрать проект командой выше и запустить на iPhone.
2. Импортировать папку с подпапкой, несколькими поддерживаемыми форматами, обложкой и повреждённым файлом. Убедиться, что ошибки видны в отчёте.
3. Повторить импорт: дубликаты не добавляются. Добавить новый файл в папку: повторное сканирование добавляет только его. Проверить повторное сканирование после перезапуска и потерю доступа к файловому провайдеру.
4. Проверить поиск, избранное и сохранение плейлистов после перезапуска.
5. Проверить перемотку, предыдущий/следующий трек, конец очереди, оба режима повтора и shuffle.
6. Заблокировать экран, проверить звук, метаданные, перемотку и команды наушников. Проверить отключение наушников, звонок и возврат аудио после него.
7. Перезапустить Pulse: очередь и позиция восстановлены, музыка сама не запускается.
8. Проверить четыре команды Siri на устройстве с выбранным языком Siri; отдельно выполнить «Команду» с названием трека.
9. Отключить интернет: импортированные треки воспроизводятся. Проверить AirPlay с реальным приёмником.

## Файлы

`Models/Library.swift` — сохраняемые данные. `Services/AudioImporter.swift` — сканирование и метаданные. `Services/LibraryStore.swift` — библиотека и папки. `Services/PlayerStore.swift` — звук и системное управление. `Intents/PlaybackIntents.swift` — Siri. `Views/` — интерфейс.
