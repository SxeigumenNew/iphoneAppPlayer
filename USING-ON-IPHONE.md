# Использование Pulse без публикации в App Store

## Срок бесплатной подписи

При подписи обычным бесплатным Apple ID профиль установки обычно действует 7 дней с момента его выдачи. Если установщик показывает меньше, ориентируйтесь на конкретную дату окончания: он мог использовать ещё действующий профиль, выданный раньше.

После окончания срока Pulse перестанет запускаться. Само истечение профиля не удаляет приложение, импортированные файлы и плейлисты. Для восстановления запуска обновите подпись через установщик. Пересобирать неизменённый исходный код ради этого не требуется.

Устанавливайте поверх существующей версии, используя тот же Apple ID и тот же конечный Bundle ID. Проще всего использовать тот же установщик с теми же параметрами. При изменении Bundle ID получится отдельное приложение с другой библиотекой. Удаление Pulse с телефона удалит его локальные файлы; храните исходную музыку отдельно.

Бесплатная Personal Team также ограничивает число установленных приложений с такой подписью: до 3 на устройстве. Срок бесплатного профиля — правило Apple, а не ограничение кода Pulse.

Источник: [Apple — Developer account overview](https://developer.apple.com/help/account/basics/about-your-developer-account), раздел **Enable a personal team in Xcode**.

## Режим разработчика

Developer Mode — штатная настройка iOS для запуска приложений с подписью для разработки. Его можно оставлять включённым во время использования такой сборки Pulse; при выключении она перестанет запускаться до повторного включения режима.

Apple предупреждает, что этот режим снижает безопасность устройства, открывая дополнительные возможности разработки и отладки. Подпись приложений, изоляция приложений и обычные запросы разрешений продолжают действовать. Доверяйте только своим компьютерам и приложениям из известных исходников.

Для приложений из TestFlight режим разработчика не нужен. Официальная инструкция: [Apple — Enabling Developer Mode on a device](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device).

## Обновление приложения и обновление подписи

Это две отдельные операции:

- При изменении кода GitHub Actions собирает новый `Pulse-unsigned.ipa`. Его нужно заново подписать и установить поверх прежнего приложения.
- Если код не изменялся, но срок профиля подходит к концу, достаточно обновить подпись тем же установщиком. Можно использовать прежний IPA.

Sideloadly поддерживает автоматическое обновление подписи. Для этого должен работать его фоновый компонент, а компьютер должен иметь интернет и видеть телефон по USB или через настроенное Wi-Fi-подключение. Строка о подготовке к auto-refresh сама по себе не подтверждает, что установка или последующее обновление подписи завершились успешно. См. [FAQ Sideloadly](https://sideloadly.io/faq).

Если используется другой установщик, возможность и условия автоматического обновления нужно проверять отдельно; не все программы поддерживают его.

## Долговременное использование

- **Бесплатная подпись:** подходит для личной разработки, но требует регулярного продления и работающей авторизации Apple в установщике.
- **Платный Apple Developer и установка на зарегистрированный iPhone:** позволяет использовать профили с более длительным сроком. Профили и сертификаты всё равно нужно обслуживать. Публичная публикация не требуется.
- **TestFlight:** удобнее получать обновления через приложение Apple. Нужны членство Apple Developer, отдельно настроенная подпись для App Store Connect и загрузка сборок. Каждая сборка доступна до 90 дней после загрузки; перед истечением публикуется следующая тестовая сборка. Публичный выпуск в App Store не обязателен. Внешнее тестирование может требовать Beta App Review.

Само оформление платного членства не меняет уже установленную бесплатную подпись: потребуется настройка выбранного способа распространения.

Источники: [Apple — способы распространения](https://help.apple.com/xcode/mac/current/en.lproj/dev31de635e5.html), [Apple — TestFlight](https://testflight.apple.com/), [Apple — TestFlight overview](https://developer.apple.com/help/app-store-connect/test-a-beta-version/testflight-overview/).
